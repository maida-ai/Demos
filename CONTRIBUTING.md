# Contributing to Maida demos

## Versioning

This repository contains examples rather than a published package. Pin and test each demo against the Maida CLI, Action, and any adapter versions it uses. Do not infer compatibility from matching version numbers across repositories. If this repository publishes numbered releases, use the tested Maida engine's `MAJOR.MINOR` compatibility line, an independent `PATCH` number, and immutable full `vMAJOR.MINOR.PATCH` tags. No release is required for an engine update unless the demos have been reviewed and tested against it. See the [Maida versioning policy](https://github.com/maida-ai/maida/blob/main/CONTRIBUTING.md#versioning-and-compatibility).
